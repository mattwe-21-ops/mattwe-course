# MattweTuttoTech - Area Quiz Riservata
Questo repository contiene il sistema di autenticazione per l'accesso ai quiz gratuiti di MattweTuttoTech. Il sito è collegato a Supabase per la gestione degli utenti e reindirizza al Google Site principale dopo il login.

## Configurazione per GitHub Pages
I file presenti in questo archivio (index.html, script.js) sono ottimizzati per essere estratti e pubblicati direttamente nella root principale del repository per l'attivazione di GitHub Pages.
